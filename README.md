# Policy Change Impact and Remediation Agent  By Dheeraj Patidar

A full-stack application for analyzing the impact of policy changes on organizational controls, evidence, remediation actions, and accepted risks.

The system combines deterministic policy comparison with Gemini-assisted control mapping and mandatory human review.

---

## Features

### Policy Management

- Store multiple versions of the same policy
- Upload PDF, DOCX and TXT files
- Extract policy text
- Detect policy sections
- Preserve source text and versions
- SHA-256 content hashing

### Control Register

- Maintain organizational controls
- Control owner and department
- Control type and status
- Evidence register
- Versioned control updates
- Automatically detect stale assessments

### Policy Comparison

The system deterministically identifies:

- Added requirements
- Removed requirements
- Modified requirements

The exact previous and new policy text is preserved for reviewer verification.

### AI Impact Mapping

Google Gemini is used to suggest possible relationships between changed requirements and organizational controls.

AI output includes:

- Suggested control
- Confidence
- Explanation
- Missing context
- Evidence review suggestion

AI is not allowed to invent control IDs.

All AI suggestions initially have:

possible impact + pending reviewer decision

### Human Review

Reviewers can:

- Accept AI mappings
- Reject AI mappings
- Correct AI mappings

Accepted or corrected mappings become confirmed impacts.

### Remediation

Confirmed impacts can have remediation actions including:

- Owner
- Description
- Priority
- Due date
- Status
- Approval
- Completion tracking

### Risk Acceptance

A reviewer can document risk acceptance with:

- Reason
- Review date
- Accepted by
- Status

Risk acceptance can later be revoked.

### Deterministic Metrics

Dashboard metrics are not generated by AI.

The backend calculates:

- Mapped
- Unmapped
- Compliant
- Unresolved
- Pending review
- Confirmed impacts
- Active risk acceptance

### Stale Assessment Detection

Assessments preserve the exact control version used when the assessment was created.

When a control is updated:

Control Version 1 → Version 2

assessments using Version 1 are automatically marked:

STALE

### Audit History

The application records:

- Assessment creation
- Policy comparison
- AI mapping execution
- Mapping acceptance
- Mapping rejection
- Mapping correction
- Remediation creation
- Remediation updates
- Remediation approval
- Risk acceptance
- Risk revocation
- Control updates
- Stale assessment events

Where applicable, before and after state is preserved.

### Final Impact Report

A reviewed report contains:

- Policy versions
- Requirement changes
- Deterministic metrics
- Confirmed control impacts
- Unmapped requirements
- Rejected AI suggestions
- Pending human review
- Remediation actions
- Risk acceptances
- Stale warnings
